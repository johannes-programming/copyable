Overview
--------

This project provides a copyable ``ABC``.

Installation
------------

To install ``copyable``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install copyable

Typing
------

The typing conforms strictly to ``mypy``.

.. container:: versionadded

    **Added in version 1.1.**

Features
--------

``class copyable.Copyable()``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This abc allows for copyable descendent classes.

``__slots__ = ()``
^^^^^^^^^^^^^^^^^^

``__hash__ = None``
^^^^^^^^^^^^^^^^^^^

``copy() -> Self``
^^^^^^^^^^^^^^^^^^

This abstract method is meant to duplicate the object.

``copyable.tests.test() -> unittest.TextTestResult``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This project can be tested through its ``test`` function.

.. code-block:: python

    import copyable.tests
    copyable.tests.test()
